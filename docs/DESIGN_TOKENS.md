# HCI and design tokens

- Product style: welcoming minimalist financial dashboard, clarity over density.
- Colors: primary deep green `#153c35`, accent `#2f8066`, mint `#e7f5ed`, peach `#fff0e4`, lavender `#eeebfb`, canvas `#f6f8f7`.
- Typography: Plus Jakarta Sans for headings; DM Sans for content, system fallbacks.
- Spacing: 4/8/12/16/24/32 px rhythm; rounded 11–22 px controls/cards.
- Layout: desktop left sidebar, mobile five-tab bottom navigation and floating add action.
- Accessibility: explicit labels, keyboard focus rings, sufficient text contrast, reduced motion, empty/error states, confirmation for destructive actions.
- Core flows: Add allowance → preview → allocation; Needs/Wants → record expense → updated balance; Savings → mark external transfer; Coach → contextual answer or offline fallback.
